## สิ่งที่อยู่ใน GitHub / Apps Script
- GitHub: ไฟล์หน้าเว็บทั้งหมดในโฟลเดอร์นี้ **ยกเว้น Code.gs และ appsscript.json** — ไม่มีคีย์ ไม่มี URL /exec ไม่มีข้อมูลม้วน (`config.js` เว้น apiUrl ว่างไว้)
- Apps Script: `Code.gs` (ACCESS_KEY อยู่ใน Script properties เท่านั้น)
- ข้อมูลทั้งหมดอยู่ใน Google Sheet

## อัปเดตจาก 1.1 → 1.2
1. GitHub → Add file → Upload files → ลาก `index.html app.js styles.css scanner-worker.js qrcode.js THIRD-PARTY.md README.md` (และไฟล์อื่นได้ ทับของเดิม) → Commit changes
2. Apps Script → วาง `Code.gs` ใหม่ทับทั้งไฟล์ → Save → เลือก `setupRollScan` → Run (ครั้งเดียว จะสร้างชีต "ประวัติสแกน"; คีย์เดิมไม่เปลี่ยน)
3. Deploy → Manage deployments → ✏️ แก้ deployment เดิม → Version: **New version** → Deploy (URL /exec เดิมใช้ต่อได้)

## เชื่อมต่อ (ทำครั้งเดียวต่อเครื่อง)
- เครื่องแรก: เปิดเว็บ → ตั้งค่าการเชื่อมต่อ → ใส่ URL /exec + ACCESS_KEY → เชื่อมต่อ เครื่องจะจำไว้ ไม่ต้องใส่อีก
- เครื่องอื่น: ที่เครื่องแรกเปิด "ตั้งค่าการเชื่อมต่อ" จะมี QR "เชื่อมเครื่องอื่นในครั้งเดียว" → ให้อีกเครื่องสแกนด้วยกล้องปกติ หรือกดคัดลอก/แชร์ลิงก์ส่งให้ เปิดแล้วเชื่อมเองทันที
- ลิงก์/QR นั้นมีคีย์อยู่ ส่งเฉพาะคนในทีม ถ้าหลุด: ลบ ACCESS_KEY ใน Script properties → Run `setupRollScan` (ได้คีย์ใหม่) → เชื่อมเครื่องแรกใหม่แล้วแชร์ QR ใหม่
- "ตัดการเชื่อมต่อ" = ลบคีย์และข้อมูลที่เก็บไว้ออกจากเครื่องนั้น

## มีอะไรใหม่ใน 1.2
- เชื่อมครั้งเดียว จำในเครื่อง + แชร์ด้วย QR/ลิงก์ (คีย์อยู่หลัง # จึงไม่ถูกส่งไป GitHub และถูกลบออกจากแถบที่อยู่ทันที)
- เก็บรายการ ISN ไว้ในเครื่อง เปิดแอปแล้วสแกนได้ทันที แล้วค่อยอัปเดตจากชีตเบื้องหลัง + อัปเดตเองทุก 3 นาที
- ถ้าไม่เจอในเครื่อง จะถามชีตล่าสุดก่อนขึ้น "ไม่พบ" (เห็นม้วนที่เครื่องอื่นเพิ่งเพิ่ม)
- ISN ซ้ำในชีตไม่ทำให้ระบบล่ม — ใช้แถวแรกและขึ้นเตือนว่าแถวไหนซ้ำ
- แถวที่เพิ่มจากแอปมีคอลัมน์ `added_by_app` (เวลา) และ `added_by` (ชื่อผู้เพิ่ม) ต่อท้ายชีต
- ชีต "ประวัติสแกน": ทุกการสแกนบันทึก เวลา / ผู้สแกน / ISN / พบ-ไม่พบ-เพิ่มใหม่ / ผลเทียบ QR (เช่น "ต่าง: kgs 29→30") — ส่งเป็นชุด เน็ตหลุดเก็บไว้ส่งทีหลัง
- ชื่อผู้สแกนตั้งได้ในหน้าตั้งค่า (ถามครั้งแรกตอนเปิดกล้อง)

รองรับ QR ฉลากรูปแบบ เกรด|ISN|ความกว้าง|kgs|diameter|meter และบาร์โค้ด Code39 จะใช้ ISN ค้นชีตก่อน ค่าใน QR แสดงแยกเพื่อเทียบ ไม่มีการแทนค่าชีตอัตโนมัติ

## มือถือ iPhone / Android
- **Android:** ใช้ Google Chrome (กล้องจำสิทธิ์ให้เลย) และจะใช้ตัวอ่านบาร์โค้ดในตัว Chrome คู่กับ ZXing อัตโนมัติ ป้ายสถานะกล้องจะขึ้นว่า "2 ตัวอ่าน"
- **iPhone:** ใช้ Safari หรือ Chrome ก็ได้ (บน iPhone ทั้งสองตัวใช้เอนจินเดียวกัน) ต้องเป็น iOS 15.4 ขึ้นไป แนะนำ Safari เพราะตั้งอนุญาตกล้องถาวรได้: แตะ aA ที่แถบที่อยู่ → การตั้งค่าเว็บไซต์ → กล้อง → อนุญาต
- iPhone ปิดเสียงด้วยสวิตช์ข้างเครื่อง เสียงบี๊บจะเงียบ (iPhone ไม่สั่นจากหน้าเว็บ)
- iPhone รุ่น Pro โฟกัสใกล้ไม่ได้: ถอยห่างราว 20–30 ซม. แล้วซูม 2× หรือเลือกกล้อง "Back Dual Wide / Triple Camera" (แอปจำกล้องที่เลือกไว้)
- ถ้า "เพิ่มไปยังหน้าจอโฮม" บน iPhone ไอคอนนั้นแยกที่เก็บข้อมูลจาก Safari ต้องเชื่อมอีกครั้ง: คัดลอกลิงก์เชื่อมต่อ แล้ววางในช่อง Apps Script URL ระบบจะเติมคีย์ให้เอง
- Safari ลบข้อมูลเว็บที่ไม่ได้เปิดเกิน 7 วัน ถ้าหายก็สแกน QR เชื่อมต่อใหม่ได้
